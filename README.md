# AntiScroll 🚀

AntiScroll replaces mindless phone scrolling with bite-sized, AI-generated micro-learning articles and interactive mini-games (Wordle, Flashcards, Concept Match, Crosswords, Word Search).

## Quick Start

Run the launcher script to build and start both the PWA frontend and NAS backend:

```bash
./start.sh
```

- **Frontend PWA:** [http://localhost:5173](http://localhost:5173)
- **Backend NAS REST API:** [http://localhost:8000](http://localhost:8000)
- **Swagger OpenAPI Docs:** [http://localhost:8000/docs](http://localhost:8000/docs)
